# self-review — PR を出す前のセルフレビュー

手順と観点の正本は `docs/rules/self-review.md`。このファイルには内容を書き足さない。

1. `docs/rules/self-review.md` を読む
2. `docs/rules/verification.md` の手順で、ビルドと表示の確認を通す
3. `git diff main...HEAD` を、`docs/rules/self-review.md` の「見る観点」でレビューし、指摘を「必ず直す／直したほうがいい／提案」に分けて出す。この会話で実装もしていた場合は、新しい会話でやり直すよう利用者に伝える
4. 「必ず直す」を直して、2 に戻る。2周目からは、直した部分だけを見る
5. 「必ず直す」が0件になるか、3周したら終わり。残した指摘と理由、PR の「確認したこと」に書く1行を報告する
