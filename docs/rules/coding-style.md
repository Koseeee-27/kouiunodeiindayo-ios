# コーディング原則（言語非依存）

Swift 固有の決まりは `docs/rules/swift.md`。ここは言語を問わない最低限の原則のみ。

## 原則

- **動くものを小さく積む**。完璧な抽象化より、動作確認できる単位で進める
- **読みやすさ優先**。ハッカソンでも「2日後の自分と相方」が読者。凝った書き方より素直な書き方
- 命名は英語・意味が分かる名前で。略語を発明しない
- コメントは「なぜ」を書く。「何をしているか」はコードで表現する
- エラーは握りつぶさない。最低限ログに残す
- シークレット（APIキー・トークン）をコードに直書きしない。リポジトリにも入れない

## AI に書かせるときの注意

- 生成されたコードは動作確認してからコミットする（`docs/rules/verification.md` の手順を通す）
- 使っていない import・関数・ビューを残さない（AI は余分なコードを生みがち）
- 既存コードのスタイルに合わせる。ファイルごとに流儀が変わらないようにする
