# PR を出す前のセルフレビュー

PR を出す前に、AI に差分をレビューさせて、直して、もう一度見せる、を回す手順。
GitHub Copilot のレビューは回数に上限があるので、ふだんのレビューはこの手順で済ませ、Copilot は要所だけに使う。

## いつやるか

- PR を出す前。数分で終わる修正（誤字、文言の調整など）は省略してよい
- 省略したときも、PR の「確認したこと」に、省略した理由を書く

## 手順

1. **先に `docs/rules/verification.md` を通す**。ビルドが通らないものをレビューに回さない
2. **新しい会話に、差分を見せる**。実装した会話の続きでレビューさせない（経緯を知っている AI は、自分の書いたものに甘くなる）。次のどれかで行う
   - 同じツールの、新しいセッションやサブエージェント（実装の会話とは別の文脈で動くもの）
   - 別のツール（Claude Code で書いたなら Codex に、など）。**データまわり（`Data/`）と、こだわる画面（ホーム・仕分け）の大きな変更は、別のツールに見せる**
   - 見せるもの：`git diff main...HEAD` と、下の「見る観点」。対応する Issue があれば、その番号も伝える
3. **指摘を3つに分けて受け取る**
   - 必ず直す：バグ、データが壊れる・消える、秘密や個人の署名設定の混入、決まりへの違反
   - 直したほうがいい：読みにくさ、重複、エラーの扱いの甘さ
   - 提案：好みの範囲。時間があれば
4. **「必ず直す」を直して、1 に戻る**。2周目からは、直した部分の差分だけを見せればよい
5. **「必ず直す」が0件になったら終わり**。上限は3周。3周しても残った指摘と、直さないと決めた指摘は、理由と一緒に PR の「特に見てほしい点」に書いて先に進む

## 見る観点

優先度の高い順。

1. **正しさ**：ロジックの誤り、端の場合（空・nil・0件）、エラーの握りつぶし、写真ファイルの作り忘れ・消し忘れ
2. **秘密と署名**：API キーなどの直書き、個人の署名設定（Team ID、`Config/Local.xcconfig`）の混入。`project.pbxproj` が変わっているなら、人が Xcode で行った設定変更として説明がつくか
3. **決まりとのずれ**：`docs/rules/swift.md`（書き方）、`docs/architecture.md`（画面とデータの境界）、`docs/data-model.md`（データの形）に反していないか。決まりの中身はそれぞれのファイルが正なので、レビューの前に読む
4. **仕様とのずれ**：`docs/requirements.md` と `docs/screen-design.md` と違う作りになっていないか。違うなら、黙って直さず、人に確認する
5. **シンプルさ**：使われていないコード、不要な抽象化、既にある実装との重複

ハッカソンの作品なので、完璧主義にならない。「動く・壊れない・秘密が漏れない」を優先し、細かい書き方は「提案」に留める。

見た目、スワイプの手触り、カメラ、効果音は、コードからは確認できない。実機での確認が要る変更なら、レビューの結果の先頭に、その旨を1行で書く。

## 人がやること

- PR を出す本人が、差分を一度、自分の目で読む。AI のレビューが通っていても、自分で説明できない変更は出さない
- レビューした AI の指摘をそのまま採用しない。おかしいと思ったら、直さない理由を PR に書く

## 結果の書き方（PR の「確認したこと」に書く）

```
セルフレビュー：済（Claude Code の code-reviewer で2周。残した指摘：なし）
セルフレビュー：済（Codex の /review で1周。残した指摘：サムネイルの大きさは実機で見てから決める）
セルフレビュー：省略（README の誤字の修正だけ）
```

## ツールごとの始め方

| ツール | 始め方 |
|---|---|
| Claude Code | `self-review` スキルを使う（「セルフレビューして」と頼めば動く）。code-reviewer エージェントが、別の文脈で差分を見る |
| Codex | 新しいセッションで `/review` を使い、観点としてこのファイルを読ませる |
| Antigravity | 新しい会話で `/self-review` を使う（`.agents/workflows/self-review.md`） |

## Copilot のレビューを頼むとき

自動では付かない。要所の PR だけ、手で頼む。

```bash
gh pr edit <PRの番号> --add-reviewer @copilot
```
