# 要件定義

このアプリで「何ができるか」を書く。機能についてはここが正。
どの画面に置くか・どう操作するかは「画面設計」に書く（ここには書かない）。

優先度の意味：
- **MVP**：これだけあれば、1回の体験（開く → 撮る → 情報を添える → 見返す）が最後まで通る最小セット
- **デモまで**：無いとデモ中に困る、またはデモの見せ場になるもの
- **余裕があれば**：App Store に出すときに要るもの、あると親切なもの

## メイン機能

| # | 機能 | 内容 | 優先度 |
|---|---|---|---|
| 1 | 起動したらカメラ | アプリを開くと自動でカメラになる。「カメラ起動中」の画面は出さない。設定で、開いたときの画面をホームに変えられる（機能25） | MVP |
| 2 | 撮って保存 | 日付は撮影日で自動で付く。手入力はなし | MVP |
| 3 | 仕分け待ち | 撮った写真は仕分けるまで溜まる。後からまとめて仕分けられる。仕分けるまでは記録に入らない（一覧にもホームにも出ない） | MVP |
| 4 | ジャンルを付ける | 「食べ物／飲み物／デザート」の3つと、「なし」。「なし」で仕分けた写真は、仕分け待ちには残らない | MVP |
| 5 | お気に入りを付ける | 付けなくてもいい。表記は仕分けでは「う、うまい」。ホーム・一覧・記録の詳細では「うまい」と出す | MVP |
| 6 | 一覧で見返す | 撮ったご飯を見返す | MVP |
| 7 | 記録の詳細 | 記録を開くと、日付、ジャンル、お気に入り、タグが見える。MVP は日付だけ | MVP |
| 23 | ホーム | 今日の一枚と、最近の写真が見える。お気に入りの記録には「うまい」と出す。今日まだ撮っていない日は、撮るように促す。一覧とは別の画面 | MVP |
| 26 | ジャンルとタグの提案 | 仕分けのとき、写真に合いそうなジャンル（食べ物／飲み物／デザート）とタグをアプリが提案する。決めるのは本人で、提案と違うジャンルでも「なし」でも仕分けられる。おまかせで AI に任せることもできる（自信がある写真だけ。自信が無い写真は残る）。提案できないとき（通信できない、判断に自信がない）は提案を出さず、いつも通り仕分けられる | デモまで |
| 27 | タグを付ける | 記録に、決まった一覧（下の「タグの一覧」）からタグを付けられる。付けなくてもいい | デモまで |
| 28 | 言葉で探す | 「前に食べたうまいラーメン」のように普段の言葉で書くと、合う記録に絞り込める。絞り込みに使うのはタグ・うまい・撮った時期 | 余裕があれば |

| # | 機能 | 内容 | 優先度 |
|---|---|---|---|
| 8 | カメラの許可 | 初めてカメラを使うときに iPhone が出す確認に、答えてもらう | MVP |
| 9 | 許可を断られたときの案内 | 断られるとカメラが映らない。「設定アプリから許可してください」と案内する | デモまで |
| 10 | 撮り直し | 撮った直後に撮り直せる。MVP は標準カメラの確認画面で行う | MVP |
| 11 | 記録を消す | 確認を挟む | デモまで |
| 12 | 仕分けのやり直し | ジャンル・お気に入り・タグを後から付け直せる | デモまで |
| 13 | 日付を直す | 日付を後から直せる | 余裕があれば |
| 14 | 仕分け待ちへの入口 | 溜めた写真を後で仕分けるための入口。何枚溜まっているかが分かる。溜まった写真を仕分けられるのは、この入口からだけ（撮った直後の仕分けは、今撮った1枚だけ）。仕分ける順番は新しい順か古い順を選べて、選んだ順番は次も覚えておく（初期設定は新しい順。順番の切り替えはデモまで） | MVP |
| 15 | 記録がゼロのときの表示 | 初めて一覧を開いたときに、何も無い画面にしない | デモまで |
| 16 | 初めて開いたときの説明 | いきなりカメラだと不親切なので、初回だけ使い方を説明する。カメラの許可の前の一言説明もここ | 余裕があれば |
| 17 | 使い方をもう一度見る | | 余裕があれば |
| 18 | カメラロールから取り込む | 他で撮った写真や、過去のご飯を入れられる。ホームから、1 枚でも、最大 30 枚まとめてでも選べる。食事でない写真は自動で除く（1 枚だけ選んだときは除かない）。日付は写真の撮影日時（入っていなければ取り込んだ日。直すときは機能13） | デモまで |
| 19 | 写真フォルダにも保存する | オン・オフを選べる | 余裕があれば |
| 20 | すべての記録を消す | | 余裕があれば |
| 21 | 保存に失敗したときの表示 | 容量不足など | 余裕があれば |
| 22 | バージョン、プライバシーポリシー、お問い合わせ | App Store に出すなら必須。デモだけなら不要 | 余裕があれば |
| 24 | SE（効果音） | 操作に効果音を付ける。お気に入りを付けたときは、ハンコを押すようなアニメーションと振動も付ける（仕分けと記録の詳細の両方。外すときは付けない）。マナーモードでは効果音を鳴らさない | デモまで |
| 25 | 開いたときの画面を切り替える設定 | アプリを開いたときの画面を、カメラ（初期設定）とホームから選べる | 余裕があれば |

## タグの一覧

タグは3種類。この一覧から選ぶ（自由入力はしない）。

| 種類 | タグ |
|---|---|
| 料理 | ラーメン、パスタ、寿司、カレー、餃子、天ぷら、唐揚げ、ピザ、ハンバーガー、ステーキ、サンドイッチ、コーヒー、お茶、お酒、ジュース、タピオカ、ケーキ、アイス、ドーナツ、焼き菓子 |
| 大分類 | 麺類、ご飯もの、パン、肉料理、魚介、揚げ物、卵料理、野菜・サラダ、汁物 |
| 系統 | 和食、洋食、中華、韓国、エスニック |

## 画面ではないが要るもの

- アプリアイコン

## 作らないこと

- 健康管理・カロリー計算
- 朝・昼・晩などの時間の分類
- 記録するときの日付の手入力
- 必須の入力項目
- レシピ
- 食べたいものリスト
- 撮った写真から商品・店の検索に飛ぶ機能（一旦没）
- ゲーム要素
- 自分で語録を選ぶ操作
- タグの自由入力

## 前提

- iPhone アプリ（iOS 26 以上）
- カメラは、MVP では iPhone 標準のカメラ画面を組み込む
- ジャンルとタグの提案（機能26）と言葉で探す（機能28）のため、写真から作った文字の情報（写っているものの名前）と、検索に書いた言葉を、インターネット経由で AI に送る。写真そのものと記録は送らない（端末内だけに保存）
- 本番の UI は、iOS 26 の Liquid Glass（Apple 標準の、半透明のガラスのような見た目）に対応させる。色や雰囲気は「デザイン要件書」

補足（iPhone 標準のカメラ画面について）：
- フラッシュ、内側カメラへの切り替え、ズームが最初から付いてくる
- 撮った後に「再撮影／写真を使用」の確認画面が必ず出る。MVP ではこの流れ（撮る → 確認 → 仕分け）で行く
- 見た目はほぼ変えられない
- カメラ画面を自分たちで作れば、確認を挟まずにそのまま仕分けに移る、見た目や動きを作り込む、ができる。UX を考えると、ここはこだわってもいいところ
- シャッター音は、日本で売られている iPhone では消せない（カメラ画面を自分たちで作っても同じ）
