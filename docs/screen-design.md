# 画面設計

「どの画面に何を置くか・どう操作するか」を書く。画面と操作についてはここが正。
機能そのものの説明は「要件定義」にあるので、ここでは番号（機能1 など）で参照する。
見た目（色・文字・雰囲気）は「デザイン要件書」。

## 記録の流れ

```
アプリを開く
  ↓
カメラ（自動で起動。「カメラ起動中」の画面は出さない）
  ↓ 撮る
撮った写真の確認（撮り直しはここ。MVP は標準カメラの確認画面）
  ↓
仕分け（今撮った1枚に、ジャンルとお気に入りを付ける）
  ↓ 仕分けずに抜けると、その写真は仕分け待ちに溜まる
ホーム（今撮った1枚が記録に入ったかを確かめる）
```

溜まった仕分け待ちの写真は、ホームか一覧の「仕分け待ちへの入口」から仕分ける。撮った直後の仕分けには出さない。

```
ホーム／一覧の仕分け待ちへの入口
  ↓
仕分け（溜まっている写真を、選んだ順番で1枚ずつ）
  ↓ 最後の1枚を仕分ける、または途中で抜ける
入ってきた画面（ホームか一覧）
```

## ナビゲーション（下タブ）

画面の下に、タブを3つ並べる。左から「カメラ」「ホーム」「一覧」。真ん中がホーム。

- ホームと一覧は、タブを押しても、横にスワイプしても行き来できる
- 下タブは、指を置いたまま横に滑らせても行き来できる。ホームと一覧は、滑らせている間に切り替わる。カメラは、指を離したときにカメラの上にいたときだけ開く（滑らせている途中では開かない）
- 仕分けの画面では、左右のスワイプを仕分けに使うので、画面を移動するスワイプは効かない
- 端末を横向きにしてもカメラにはならない（縦画面のみ）

## 画面のつながり

どの画面からどの画面へ行けるか。カメラ・ホーム・一覧への移動は下タブ。それ以外の入口の形と置き場所は、各画面の「画面詳細」に書く。

| どこから | 何をすると | どこへ |
|---|---|---|
| アプリを開く | （自動） | カメラ |
| アプリを開く（設定で、開いたときの画面をホームにしている。機能25） | （自動） | ホーム |
| アプリを開く（初回だけ） | （自動） | 初めて開いたときの説明 → カメラ |
| アプリを開く（カメラの許可を断られている） | （自動） | カメラの許可を断られたときの案内 |
| カメラ | 撮る | 撮った写真の確認 → 仕分け |
| カメラ | キャンセル | ホーム |
| カメラ | アルバムから写真を選ぶ（機能18。カメラを自作したときに置く） | 仕分け |
| カメラの許可を断られたときの案内 | アルバムから写真を選ぶ（機能18） | 仕分け |
| カメラの許可を断られたときの案内 | ホームへ | ホーム |
| 仕分け（カメラ・カメラの許可を断られたときの案内から入った） | 仕分けを終える／仕分けを抜ける | ホーム |
| 仕分け（ホーム・一覧の仕分け待ちへの入口から入った） | 最後の1枚を仕分ける／仕分けを抜ける | 入ってきた画面（ホームか一覧） |
| ホーム／一覧 | 下タブの「カメラ」 | カメラ |
| ホーム | 下タブの「一覧」、または横スワイプ | 一覧 |
| 一覧 | 下タブの「ホーム」、または横スワイプ | ホーム |
| ホーム | 仕分け待ちへの入口 | 仕分け |
| ホーム | 今日の一枚、または最近の写真をタップ | 記録の詳細 |
| ホーム | 右上の設定のアイコン | 設定 |
| ホーム（今日まだ撮っていない） | 撮るボタン | カメラ |
| 一覧 | 仕分け待ちへの入口 | 仕分け |
| 一覧 | 写真をタップ | 記録の詳細 |
| 記録の詳細 | 閉じる／記録を消す | 元いた画面（ホームか一覧） |
| 記録の詳細 | 左右にスワイプ | 前後の記録の詳細（開いた元の並び順） |
| 設定 | 閉じる | ホーム |

## 画面の一覧

| 画面 | 何をする画面か | こだわり度 |
|---|---|---|
| 起動画面 | アプリを開いた瞬間に出る画面。iPhone の仕様で必ず1枚要る。アプリのタイトルを出す | 最低限 |
| カメラ | 開いたらここ。撮るだけ | 最低限（MVP は標準カメラ） |
| 仕分け | 撮った写真を、ジャンルとお気に入りで仕分ける。撮った直後は今撮った1枚、仕分け待ちへの入口からは溜まっている写真を1枚ずつ | こだわる |
| ホーム | 今日の一枚と最近の写真を見る（機能23）。一覧とは別の画面 | こだわる |
| 一覧 | 撮ったご飯を見返す | 最低限 |
| 記録の詳細 | ホームや一覧の記録をタップすると開く | 最低限 |
| 初めて開いたときの説明 | 初回だけ出す。使い方の説明と、カメラの許可 | 最低限 |
| カメラの許可を断られたときの案内 | カメラの代わりに出す | 最低限 |
| 設定 | 使い方、保存先、記録の全消去など。まずは App Store の審査に要る機能22 だけを載せ、ほかは作るときに足す | 最低限 |

こだわり度の意味：
- **こだわる**：見た目と UI を作り込む（一旦ここまで）
- **最低限**：ちゃんと動いて、迷わなければいい

## 画面詳細

### カメラ
必要な要素：
- カメラの映像（画面全体）
- シャッターボタン
- 撮った写真の確認と撮り直し（機能10）
- 保存に失敗したときの表示（機能21）
- キャンセルを押すとホームへ（MVP の標準カメラでは、これがカメラからホームへ行く手段）
- iPhone が出すカメラの許可の確認に添える一言（機能8）：「ご飯の写真を撮って記録するために、カメラを使います。」
- アルバムから選んで記録する入口（機能18）。選んだ写真は撮った写真と同じく仕分けへ進む。MVP の標準カメラには置けないので、カメラを自作したときに置く

MVP は iPhone 標準のカメラ画面を使う（「要件定義」の前提を参照）。

### 仕分け
必要な要素：
- 仕分ける写真（1枚ずつ、カードで大きく）。仕分け待ちへの入口から入ったときは、後ろに次の写真が少し見えて、まだ溜まっているのが分かる
- 残りの枚数（例：「あと3枚」）。仕分け待ちへの入口から入ったときだけ出す
- 仕分ける順番の切り替え（新しい順／古い順。機能14）。仕分け待ちへの入口から入ったときだけ出す
- 4方向のジャンルのラベル（文字＋アイコン。すべて横書き）
- ジャンルを付ける操作（機能4）：スワイプ。上＝食べ物、左＝飲み物、右＝デザート、下＝なし
- スワイプの代わりに、ジャンルのラベルを押しても仕分けできる（スワイプができない人、画面の読み上げを使う人のため）
- お気に入りを付ける操作（機能5）：写真の右上に、半透明の「う、うまい」。押すと濃くなって、お気に入りが付く。もう一度押すと外れる
- 提案されたジャンル（機能26）。4方向のラベルのうち、提案されたものが分かる。スワイプ中の強調とは別の見え方にする
- 提案されたタグ（機能26・27）。写真のカードの外に並べる（スワイプと取り違えないように）。最初から付いた状態で出し、押すと外れる。もう一度押すと付く。出すのは提案されたタグだけ。提案に無いタグを仕分けで足す操作は置かない（足すのは記録の詳細）
- 仕分けを抜ける手段（1枚ずつ「あとで仕分ける」を選ぶ操作は置かない）

出す写真と順番：
- カメラから入ったとき：今撮った1枚だけ。溜まっている仕分け待ちの写真は出さない（撮った1枚が記録に入ったかを、すぐホームで確かめられるように）
- 仕分け待ちへの入口から入ったとき：溜まっている写真を、新しい順か古い順で出す。初期設定は新しい順。切り替えた順番は、次に仕分けるときも覚えておく

操作と、そのあと起きること：

| 操作 | 起きること |
|---|---|
| スワイプし始める | カードが指についてきて少し傾く。向かっている方向のジャンルが強調される |
| 途中で離す | カードが元の位置に戻る。何も付かない |
| 一定以上動かして離す | カードがその方向へ飛んでいく。ジャンルが付いて、次の写真が出る |
| ジャンルのラベルを押す | スワイプと同じ。ジャンルが付いて、次の写真が出る |
| 写真の右上の「う、うまい」を押す | 濃くなって、お気に入りが付く（効果音とアニメーション。機能24）。写真は次に進まない |
| 写真が出る | 提案がまだ届いていなくても、写真はすぐ出す。提案は届いた時点で出す。届かなければ出さない |
| 提案されたタグを押す | 付け外しが切り替わる。写真は次に進まない |
| ジャンルを付けて次に進む（スワイプ・ラベルを押す） | そのとき付いているタグも一緒に記録に入る。提案と違うジャンルを選んでもよい |
| 仕分けを抜ける | 入ってきた画面へ（カメラから来たときはホーム）。残りの写真は仕分け待ちに残る |
| 最後の1枚を仕分ける | 入ってきた画面へ（カメラから来たときはホーム） |
| 仕分ける順番を切り替える（仕分け待ちへの入口から入ったとき） | 選んだ順番で出し直す。仕分け済みの写真は戻らない |
| 途中でアプリを閉じる | 写真は消えない。仕分け待ちに残る。次に開いたときは、いつも通りの画面（カメラ。設定していればホーム） |

状態（同じ画面の見た目の違い。デザインはこの単位で要る）：
- 通常
- スワイプ中（上・左・右・下）
- お気に入りが付いているとき（「う、うまい」が濃い）
- 提案がある／ない（通信できない、判断に自信がない、まだ届いていない）
- カメラから入ったとき（今撮った1枚だけ。残りの枚数と後ろのカードは出さない）
- 仕分け待ちへの入口から入ったとき：1枚だけのとき／複数枚溜まっているとき（新しい順・古い順）
- 初回だけの操作ガイドの重ね表示（機能16）

### ホーム
必要な要素：
- 今日の一枚（機能23）。大きく出す。仕分け待ちの写真は出さない
- 今日まだ撮っていない日は、今日の一枚の代わりに「今日はまだ撮っていません」と、撮るボタン
- 最近の写真（機能23）。仕分け待ちの写真は出さない
- お気に入りの記録には「うまい」と出す（今日の一枚・最近の写真の両方）。ホームからお気に入りを付けることはできない（一覧と同じ）
- 記録の詳細への入口（今日の一枚、または最近の写真をタップ）
- 仕分け待ちへの入口と、溜まっている枚数（機能14）
- カメラへの入口は下タブ（「ナビゲーション」を参照）
- 設定への入口。右上のアイコン

状態：
- 今日の一枚がある
- 今日まだ撮っていない（撮影を促す）
- 仕分け待ちがある／ない

### 一覧
必要な要素：
- 撮ったご飯の写真の並び（写真アルバムのような形。カレンダー形式にはしない）。仕分け待ちの写真は出さない
- お気に入りの記録には「うまい」と出す。ジャンルは出さない。一覧からお気に入りを付けることはできない（付けるのは仕分けと記録の詳細）
- 記録の詳細への入口（写真をタップ）
- カメラへの入口は下タブ（「ナビゲーション」を参照）
- 仕分け待ちへの入口と、溜まっている枚数（機能14）
- 記録がゼロのときの表示（機能15）
- 言葉で探す（機能28）。書いた言葉に合う記録だけを並べる

状態（仮）：
- 記録がゼロ
- 記録はあるが、仕分け待ちが0枚（仕分け待ちへの入口は出さない）
- 記録があり、仕分け待ちもある
- 枚数が多くて画面に収まらない（スクロール中の見た目）
- 言葉で絞り込んでいる／合う記録が無い（機能28）

### 記録の詳細
必ず表示するもの：
- 写真
- 日付（機能7）
- 閉じる

操作と、そのあと起きること：

| 操作 | 起きること |
|---|---|
| 閉じる | 元いた画面（ホームか一覧）の、元いた位置に戻る |
| ジャンル・お気に入りを付け直す（機能12） | その場で変わる。保存ボタンは無い。ジャンルは「なし」の選択肢を置かず、選択中のジャンルをもう一度押すと外れる。お気に入りは「うまい」を押して付け外しする（表記は仕分けだけ「う、うまい」、ほかの画面は「うまい」） |
| タグを付け直す（機能12・27） | その場で変わる。保存ボタンは無い。タグの一覧から足す・外す |
| 左右にスワイプする | 開いた元の並び（ホーム・一覧の新しい順）で、前後の記録の詳細に移る。いちばん新しい・いちばん古い記録では、それ以上動かない。移った先でも、うまい・ジャンル・タグの付け直し・記録を消すが同じように使える |
| 日付を直す（機能13） | その場で変わる |
| 記録を消す（機能11） | 確認が出る。「消す」で元いた画面に戻り、その写真は無くなる。「やめる」で何も起きない |

### 初めて開いたときの説明
必要な要素：
- 使い方の説明（機能16）
- カメラの許可の前の一言説明（機能16）

### カメラの許可を断られたときの案内
必要な要素：
- 設定アプリから許可する方法の案内（機能9）と、設定アプリを開くボタン
- アルバムから選んで記録する入口（機能18）。カメラが使えなくても記録できるようにする
- ホームへ戻る手段

カメラの許可が「断られた」「制限されている（スクリーンタイムなど）」のどちらでもこの画面を出す。標準カメラをそのまま出すと、真っ黒でシャッターが効かない画面になるため。

### 設定
必要な要素：
- 開いたときの画面の切り替え（機能25）
- 使い方をもう一度見る（機能17）
- 写真フォルダにも保存する、のオン・オフ（機能19）
- すべての記録を消す（機能20）
- バージョン、プライバシーポリシー、お問い合わせ（機能22）
- 閉じる手段。閉じるとホームに戻る。下タブは出さない
