# 実装計画: 一覧で記録を選んで、まとめて消す

## 概要

一覧の上の行の右端に「選択」を置き、選ぶモードで写真をタップして選び、まとめて消せるようにする（確認つき）。こうせいが実機のデバッグで、試しに撮った・取り込んだ記録を片付けるのにも使う。まとめてジャンルを変えるのは別の Issue（この Issue の後）。対応する Issue：#118（親 #9）。まとめてジャンルを変えるのは #119。対応する機能：機能11 記録を消す（一覧からまとめて）。

**#85（一覧の言葉で探す。`RecordListView.swift` を触る）がマージされたあと**、main から `feat/118-bulk-delete` を切って作る。この計画は #85 のブランチ（`origin/feat/85-word-search`）の `RecordListView` を前提に書いている（`displayed`・`condition`・`DetailSelection` がある形）。

**目安：2〜2.5 時間**（選ぶモード 1 時間・まとめて消す 30 分・下タブ 20 分・テストとプレビュー 30 分）。13:00 の Topa'z 投稿までに入れる（こうせいの決定）。

## 作り方

### 書き込み（`Data/RecordStore.swift`）

```swift
/// まとめて消す（一覧の選ぶモード）。記録を全部消してから 1 回だけ保存し、そのあと写真とサムネイルのファイルを消す。
/// 保存に失敗したら全部取り消して投げ直す（一部だけ消えた状態にしない）。ファイルの削除に失敗しても記録は戻さない（ログに残す）。
func delete(_ records: [Record]) throws
```

- 中身は今の `delete(_ record:)` と同じ流れを、まとめて行う（先に `id` と `photoFileName` を控える → `modelContext.delete` を全部 → `save()`（失敗したら `rollback()` して投げ直す）→ ファイルを消す）
- `deleteAll()` は今のまま（1 件ずつ）。変えない

### 選ぶモード（`Features/List/RecordListView.swift`）

- 状態：`@State private var isSelecting = false`、`@State private var selectedIDs: Set<UUID> = []`、`@State private var isDeleteConfirmationShown = false`、`@State private var isDeleteFailureShown = false`
- 上の行：タイトルロゴの行の右端に、選ぶモードでないときは「選択」、選ぶモードのときは「キャンセル」。記録が 0 件のときは「選択」を出さない
- 選ぶモードのときは、区切り線の下に 1 行：「n 件を選択」と「すべて選択」（全部選んでいるときは「選択を解除」）。「すべて選択」は `displayed` の全部（絞り込み中は絞り込んだ結果だけ）
- 写真の `photoButton`：選ぶモードのときは、押すと `selectedIDs` に足す・外す（詳細は開かない）。写真の右下に丸い印（選んでいないとき：白い丸の枠。選んだとき：墨の丸に白いチェック）、選んだ写真は黒を薄く重ねて少し暗くする。「うまい」のハンコ（右上）とは重ならない
- 選ぶモードの間は、仕分け待ちの入口と言葉で探す欄を押せないようにする（見た目は残す。押すと混ざるため）
- 絞り込みを変えた・やめたとき：`selectedIDs` のうち `displayed` に無いものを外す
- 下の操作のバー：選ぶモードのとき、下タブの場所に「消す」（`trash`。何も選んでいないときは押せない）。押すと確認
- 確認：`alert("\(n) 件の記録を消しますか？", …)`、本文「写真も消えます」、「消す」（`.destructive`）「やめる」（`.cancel`）。詳細の 1 件の確認と同じ形（iOS 26 の `confirmationDialog` は「やめる」を出さないため `alert`）
- 消す：`store.delete(selected)` → 成功したら `selectedIDs` を空にして選ぶモードを出る。失敗したら「消せませんでした」のアラート（詳細と同じ）。消した記録の詳細は開いていない（選ぶモードの間は開けない）ので、詳細の並びの心配は無い
- 読み上げ：写真のボタンは、選ぶモードのとき「2026年9月10日 の写真。選択中」／「…。選択されていません」、ヒント「押すと選びます／外します」。「選択」「キャンセル」「すべて選択」「消す」に `accessibilityLabel`
- 一覧から `RootView` へ、選ぶモードかどうかを伝える：`RecordListView(onSelectingChange: (Bool) -> Void = { _ in })` を足し、`isSelecting` が変わったら呼ぶ

### 下タブ（`App/RootView.swift`）

- `@State private var isListSelecting = false`。`RecordListView(onSelectingChange: { isListSelecting = $0 })`
- 選ぶモードの間は、`RootTabBar` を出さない（その場所に一覧の操作のバーが出る）。ページャーの横めくりを止める（取り込み中と同じく、`TabView` の上に透明な面を重ねて横のスワイプを受け止めるか、`page` を固定する。#102 で `scrollDisabled` が効かなかったので、取り込み中の幕と同じやり方にする）
- 操作のバーは、`RecordListView` の `safeAreaInset(edge: .bottom)` で出す（`RootTabBar` と同じ高さ・同じガラスの見た目。`Theme` の定義を使う）
