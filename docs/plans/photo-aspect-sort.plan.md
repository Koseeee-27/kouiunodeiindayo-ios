# 実装計画: 横長・正方形の写真を、仕分けのカードで自然に見せる

## 概要

仕分けのカードで、横長・正方形の写真のときに写真の上下に白い帯（カードの地）が出ていたのを直す。対応する Issue：#108 の残り（仕分けのカード。記録の詳細は `photo-aspect-detail.plan.md` で済み）。デモでアルバムから横長の写真を取り込むと白い帯が出るため。

## 決めたこと（2026-09-27、こうせいと確認。Issue のとおり）

- カードの形を写真に合わせる。3:4 の場所の中に、写真の形のカードを真ん中に置く。枠と縁のラベルはカードに付いてくる
- スワイプの手触り・ラベルの位置が変わるので、変えるのは最小にする。ドラッグと飛ばす処理（`SortCardStackView` の `dragGesture`・`commit`・`fly`・`SwipeDirection`）には触らない

## ステップ

1. `Features/Sort/SortCardView.swift` — 渡された 3:4 の場所の真ん中に、写真の形のカード（地・写真・枠・右上の「う、うまい」）を置く。余りは透明で、押しても何も起きない。読み込む前は今までどおり 3:4 の地。読み込んだら写真の縦横比を呼ぶ側に知らせる（`onPhotoAspect`）
2. `Features/Sort/SortCardStackView.swift` — 置き方だけ直す。カードの重なり（`cardStack`）の大きさは 3:4 のまま。縁のラベル（上下左右）は、3:4 の場所ではなく、その真ん中にある手前のカードの形（知らせてもらった縦横比）の縁に付ける。ドラッグ・飛ばす処理・後ろのカードの縮め方とのぞかせ方・スタンプの位置は変えない
3. `Features/Sort/SortPreviewData.swift`・`SortView.swift` — 縦長・横長・正方形の写真（形の分かる格子と丸）の仕分け待ちに提案を付けたプレビュー（ふつう・SE 相当・ドラッグ途中・後ろのカードの重なり）を足す。直す前にも同じ条件で撮って並べる
4. `docs/screen-design.md` — 仕分けの「仕分ける写真」の行に「切らずに全体を出す。どの比率でも写真の形のまま枠を付け、置く場所（3:4）の真ん中に置く。ラベルはカードの縁に付く」を足す。`docs/architecture.md` の `SortCardView` の行も合わせる

## リスク

- 後ろのカードが手前と違う形のとき（手前が横長・後ろが縦長など）、後ろのカードが手前の上下からはみ出し、ラベルとタグの行にかぶる（実装してプレビューで分かった）。→ 後ろのカードは、手前のカードの形の枠の中に収める（`SortCardView` の `boxAspectRatio`）。仕分けが決まったら、せり上がりのバネと一緒に自分の形の大きさまで広がるので、手前に来たときに跳ねない
- ドラッグ中のスタンプ（「デザート」など）は、横長のカードでは右上の「う、うまい」に重なる。直す前も縦長のカードで少し重なっていたので、今回は位置を変えない
- 横長のカードでは、上下のラベルが 3:4 の場所の内側に入る。上下のラベルの分の空き（`topOuterHeight` など）は今までどおり取るので、場所の大きさは変わらず、カードの外に空きが残る
- 仕分けたあと、次のカードの形に合わせてラベルが動く（アニメーションは付けない）。手触りは実機で確かめる

## 完成の確認方法

- プレビューのスクショ（縦長・横長・正方形 × ふつう・SE、提案の点線とチップあり、ドラッグ途中、後ろのカードの重なり）を直す前と後で並べる
- 仕分けのテストと全体のテスト（見た目と置き方だけの変更なので、足すテストは無い）
- 実機で、横長の写真のスワイプ・ラベルを押す・「う、うまい」・おまかせの手触り（シミュレータ担当と、こうせいの実機）
