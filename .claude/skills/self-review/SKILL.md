# self-review — PR を出す前のセルフレビュー

手順と観点の正本は `docs/rules/self-review.md`（どの AI ツールでも共通）。このスキルは、それを Claude Code で回すための入口。

1. `docs/rules/self-review.md` を読む
2. verification-loop スキルで、ビルドと表示の確認を通す
3. **code-reviewer エージェント**に差分（`git diff main...HEAD`）をレビューさせる。自分でレビューしない（実装した会話の続きだと甘くなる）。対応する Issue があれば番号を渡す
4. 「必ず直す」を直して、2 に戻る。2周目からは、直した部分の差分だけを渡す
5. 「必ず直す」が0件になるか、3周したら終わり。残した指摘と理由、PR の「確認したこと」に書く1行（`docs/rules/self-review.md` の「結果の書き方」）を報告する

データまわり（`Data/`）や、ホーム・仕分けの大きな変更のときは、終わりに「別のツール（Codex など）にも見せることを勧める」と伝える。
